
# Linux Server Monitoring and Automated Backup on AWS EC2

## Project Overview
A beginner-friendly Linux cloud project deployed on AWS EC2 using Ubuntu Linux and Bash scripting.

<img width="1447" height="921" alt="Screenshot 2026-11-25 202132" src="https://github.com/user-attachments/assets/a16e3515-58d3-4c0f-b815-bad1ff2cbdf1" />


## Features
- CPU usage monitoring
- RAM usage monitoring
- Disk usage monitoring
- Server uptime monitoring
- Automated file backups
- Scheduled tasks using Cron

## Technologies
- AWS EC2
- Ubuntu Linux
- Bash Scripting
- Cron
- SSH
- Git and GitHub

## Project Structure

linux-cloud-project/
├── scripts/
│   ├── system_monitor.sh
│   └── backup.sh
├── logs/
├── backups/
├── data/
├── .gitignore
└── README.md

## Implementation
1. Created an Ubuntu EC2 instance.
2. Connected using PuTTY and SSH.
3. Developed Bash monitoring script.
4. Developed automated backup script.
5. Scheduled tasks using Cron.
